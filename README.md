# 底池账本

单一管理员使用的德州筹码记分网页。数据只保存在当前浏览器的 LocalStorage 中，适合本地预览与流程验证。

## 使用

直接用浏览器打开 `index.html`，即可开始使用。也可以在项目目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173`。

## 记账规则

- 带入与补充带入会增加净带入。
- 带出 / 还码会减少净带入。
- `净带入 = 带入 + 补充带入 − 带出 / 还码`
- `筹码盈亏 = 剩余筹码 − 净带入`
- 在结算区可选设置 `1 元 = N 筹码`，系统会额外展示金额盈亏；该设置不会修改筹码数据。

每条流水都会保存发生时间、创建时间和最后修改时间。新增、修改与删除均保存在审计记录中；删除的流水不会显示在日常账本中，但可在审计抽屉追溯。

## 测试

```bash
npm test
```

## 限制

不含登录、云端同步、跨设备数据共享或多人协作。清除浏览器站点数据会清除账本数据；正式使用前建议先在浏览器开发者工具中导出 LocalStorage 备份。
